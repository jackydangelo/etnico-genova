## Come contribuire
Ristoranti etnici aGenova è una selezione curata manualmente da una singola persona.

Per aggiungere, modificare o eliminare ristoranti occorre semplicemente i seguenti passi:

- Clona questo repository
- Aggiorna il file ristoranti.yaml (per aggiungere, basta inserire nome, tipo di cucina e indirizzo del ristorante)
- Richiedi una pull request

Ogni eventuale richiesta verrà valutata e verificata prima di essere accettata.
